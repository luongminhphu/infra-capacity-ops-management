## Phụ lục E — Cấu trúc frontend (FE-*)

### Rà soát cấu trúc frontend — vòng 2 (chỉ đọc)

Phạm vi: `frontend/` tại `origin/main` (`0e3ee71`, PR #67). Không sửa file trong repo. Đối chiếu với
`design-system/ico/MASTER.md` và `pages/{danh-sach,trang-chu,dieu-hanh}.md`.

Cách làm: đếm token bằng regex `var(--x)` (CSS) và chuỗi `--x` (JS / HTML, gồm `getPropertyValue` trong
`chartPalette()`); tìm class chết bằng cách so class trong `styles.css` với chuỗi trong `index.html` + `js/**`, rồi
lọc tay các class ghép động (`tone-rule-${…}`, `lv-${…}`, `ct-party-${…}`, `tone-${r.tone}`); tìm hàm chết bằng
đếm tham chiếu toàn bộ `js/` + `index.html`; XSS bằng một lexer nhỏ trích **4 616** biểu thức `${…}` trong template
literal, bỏ các biểu thức đã qua `esc()` / helper đã escape / số, rồi đọc tay ~700 biểu thức còn lại và mọi phép gán

##### FE-01 — Alias trạng thái `--ok/--warn/--bad/--crit` là alias dùng nhiều nhất

Kết luận: **không tìm thấy chỗ nào đưa chuỗi ngoài (vCenter / NetBackup / người dùng khác) vào DOM mà chưa escape.** `esc()`
(`core.js:31`) escape `& < > " '`. Các helper đã escape: `uiPill`, `uiEmpty`, `uiNote`, `uiEmptyRow`, `uiEntityLink`, `uiBullet`, `uiKpiStrip`
(`label/value/unit/sub`), `uiSmallMultiples` (`name/sub/label`), `spOpt`, `spPill`, `enVal`, `bkDate`, `licDate`, `srMulti`, `srChecks`.
Mọi `spDialog` / `spPaneOrDialog` (24 + 2 caller) đã truyền `title` qua `esc()`. Các phát hiện dưới là **hợp đồng HTML dễ vỡ**.

##### FE-40 — `history.js:468` chèn câu nhận định từ server dạng HTML thô
- `ins.innerHTML = data.insights.map(t => \`<div>${t}</div>\`)` — `insights` sinh ở `backend/app/report_pdf.py:654-690` (`_history_insights`),
  có `<b>`; tên cluster / vCenter (từ **vCenter**) đã `esc()` server-side (dòng 688). An toàn hôm nay; một lần sửa server quên `esc` là XSS lưu trữ.
- **Mức độ:** Trung bình. **Đề xuất:** server trả cấu trúc (`[{text, strong:[…]}]`) hoặc client chỉ cho phép `<b>` (escape rồi khôi phục `&lt;b&gt;`);
  thêm test backend: tên cluster `<img onerror>` không xuất hiện thô trong `insights`. **Công sức:** S.

#### Phụ lục — cách tái lập

- Đếm token: vòng lặp `grep -oP -- "var\($t(?![\w-])"` trên `styles.css` và `grep -rhoP -- "$t(?![\w-])"` trên `js/ index.html`.
- Class chết: trích `\.[a-zA-Z_][\w-]*` từ `styles.css` (bỏ `url()` và chuỗi), so khớp nguyên từ trong `index.html + js/**`, rồi grep tiền tố ghép động.
- Hàm chết: `^(async )?function NAME` và `^(const|let) NAME =`, đếm tham chiếu không đứng sau `.`.
- XSS: lexer nhỏ trích `${…}` trong template literal (4 616 biểu thức), loại biểu thức là lời gọi `esc()` / helper đã escape / thuộc tính số,
  đọc tay ~700 biểu thức còn lại + mọi `innerHTML/outerHTML/insertAdjacentHTML` có vế phải không phải template (63 chỗ).
